Skills are named sets of instructions an agent pulls in when a task calls for them. Every skill in scope is listed to the agent by name and description on each turn; the agent loads the full text only when it decides the skill applies, so a long skill costs nothing until it is used. Each skill is a folder holding a SKILL.md, which you can also edit on disk.
