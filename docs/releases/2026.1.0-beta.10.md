# ONIXLabs Studio 2026.1.0-beta.10 — what changed

**Range:** `v2026.1.0-beta.9..main` (`78b2d746`)
**Span:** 2026-10-23 → 2026-11-09
**Commits:** 421 total, 359 excluding merges

---

## Summary

Nine themes make up this beta.

Language servers do far more. C# reached parity with Visual Studio's core editing: code lenses, Run
and Debug Test from the editor, inlay hints, errors for the whole solution, call and type
hierarchy, Go to Symbol in Workspace, fix-all, formatting, and Go to Definition into framework and
package code. Rust, C and C++, TypeScript, Java, Kotlin, Go and Python then each had their servers
probed and wired the same way, so their settings reach the server, their lenses work, their
colouring is right and their status rows say what they are doing.

A Tests panel finds, runs and debugs a workspace's tests. Test frameworks are plugins: .NET,
JavaScript, Python, Rust, Go, CTest and JVM adapters find tests by reading the source, run them in
a visible terminal and show each result with its message, stack and output.

Package management left core for plugins. The Packages panel was rebuilt on them, and npm, NuGet,
PyPI, Cargo, Go modules, Maven and Gradle, vcpkg and Conan each have one. A project's own `.npmrc`
or `nuget.config` can no longer send your saved credentials or environment variables to a host it
names.

The Database Explorer arrived, modelled on SQL Server Management Studio: an Object Explorer, SQL
and Cypher queries with name completion, a results grid, a Graph view, and remembered passwords
sealed in the document. SQLite, PostgreSQL and Neo4j are engine plugins.

Settings were overhauled. They can be searched, imported and exported, and gained hundreds of new
options across the app, code editing, the terminal, version control, AI and every tool.

Agents are held to their sandbox honestly. Running a command outside the sandbox is now a
permission of its own, every such command is marked in the transcript, the agent is told what its
sandbox really allows, and local network and Docker socket access are permissions you set. Rules
you told an agent to remember are listed with Revoke.

The Solution Explorer lists what each project is made of, for Go, Rust, Python, JVM and Node
projects, and can rename and delete files. Explorers mark errors up the tree and filter by changes
and problems, and renaming a file updates what imports it.

Every modal dialog follows one standard, and the ghost button replaces the outline button
throughout.

Behind it all, a hardening pass added tests across the app and fixed over a hundred faults it found.

## Plugins

These releases come in with this beta ([#1408](https://github.com/onix-labs/onixlabs-studio/pull/1408)). Install them from the Plugin Manager, where they are listed once
Studio has the new catalogue (revision 65, carried by this build).

- **Packages panel, 0.1.0 each:** npm, NuGet, Go modules, vcpkg, Conan, Cargo, PyPI and Maven.
- **Tests panel, 0.1.0 each:** .NET Tests (xUnit, NUnit and MSTest, including projects set up in a shared
  `Directory.Build.props`), JavaScript Tests, Python Tests, Rust Tests, Go Tests, JVM Tests and CTest.
- **git 0.8.0** limits how many requests run at once against one repository, and discarding a folder no
  longer deletes what is tracked or ignored in it.
- **claude-harness 0.19.0** runs outside the sandbox only as its own permission, says so in the
  transcript, tells the agent the truth about the sandbox it runs in, and treats localhost and the Docker
  socket as agent permissions.

**Upgrade note:** update Git to 0.8.0 and Claude to 0.19.0 in the Plugin Manager. Studio offers the
updates when it starts.
