## Summary

This beta's headline is a fix for first-run setup.

A fresh installation of beta.10 could not install the plugins it offered. The setup wizard asked for
Claude, Git and the rest and each install failed, because beta.10 fetched those plugins' lockfiles from
a URL that changed every time a plugin was updated, while checking them against hashes fixed when the
build was made. Seven of the plugins beta.10 ships had been updated since. Plugin lockfiles are now
pinned to each plugin's own release, and every one is compiled into Studio, so this build installs its
plugins on a machine that has never run Studio before. A newer catalogue that lists a plugin this build
is too old to run no longer takes the plugin away; this build keeps the release it shipped with. When an
install does fail, Studio says why in words you can act on, with Try Again and Open Log Folder. And a
nightly check now proves the last three releases can still install every plugin they ship with.

Agents running in the sandbox on macOS can use `gh`, `terraform`, `gcloud` and other Go tools once you
allow the new **Certificate Checks** permission. Without it they fail every secure request, and `gh`
misreports that as an invalid token; the agent is now told that, too.

Merge conflicts are settled in the code editor, with Keep Yours, Keep Theirs and Keep Both. Go programs
and tests debug under Delve. SQL Server joins the database engines, and every engine can show how it
would run a query. Python is formatted with ruff or black. The Plugin Manager updates every plugin at
once.

## Plugins

These releases come in with this beta. Install or update them from the Plugin Manager.

- **claude-harness 0.21.0** adds the Certificate Checks permission and tells the agent when Go
  tools cannot verify TLS ([#1470](https://github.com/onix-labs/onixlabs-studio/pull/1470)).
- Released since beta.10 ([#1449](https://github.com/onix-labs/onixlabs-studio/pull/1449)):
  **claude-harness 0.20.0** (excluded commands; an explicit Allowed opens Local Network and Docker
  Socket under Prompt All), **git 0.9.0**, **github 0.7.0** (agents edit issues and pull requests),
  **dotnet-tests 0.1.1**, the **SQLite, PostgreSQL and Neo4j engines 1.4.0** (query plans, Markdown
  export), and the new **SQL Server engine 0.1.0**.

**Upgrade note:** beta.10 cannot install the plugins above; update Studio first. Once on beta.11, update
Claude in the Plugin Manager to get Certificate Checks.
