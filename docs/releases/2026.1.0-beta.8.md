## Summary

Three themes make up this beta.

Agent conversations no longer go quiet. When a background task finishes, Claude starts a turn of its
own to report on it. If that turn thought for more than 15 seconds, Studio stopped listening, and
anything it said was lost. That included any question it asked, which left the conversation stuck
until Stop. Idle sessions were also ended on a timer even while a background task was still running.
Both are fixed.

The File and Solution Explorers work with version control and with several files at once (epic
[#1041](https://github.com/onix-labs/onixlabs-studio/issues/1041)):

- **Row menus** offer the version-control commands that fit the row: Show Differences, Revert
  Changes, Undo Add, Mark Resolved, Add to Version Control, Ignore, Stop Tracking and Show History.
- **Multi-select** with ⌘-click, ⇧-click and ⇧↑/↓, with menus that act on every selected row.
- **Show Changed Files Only** narrows the tree to what version control sees as changed.
- **A status strip** along the bottom shows where the selection is.

The dock holds its shape. Tab groups have minimum sizes worked out from their tabs and panels, and
the window can't be made smaller than the layout needs. Tool tabs snap to the panel's edge while you
drag a splitter again. Menus opened from an auto-hidden panel no longer close it.

F7 in a diff opens Studio's own accessible change reader.

## Plugins

These releases come in with this beta:

- **git 0.5.0** adds Ignore and Stop Tracking.
- **git 0.6.0** adds file and folder history, following a file across renames.

Both work with beta.7 and earlier too: older builds simply don't offer the new commands.
