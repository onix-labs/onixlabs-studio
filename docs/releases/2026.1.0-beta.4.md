# ONIXLabs Studio 2026.1.0-beta.4 — what changed

**Range:** `v2026.1.0-beta.3..main` (`7e3be7b9`)
**Span:** 2026-09-01 → 2026-09-06
**Commits:** 51 total, 33 excluding merges

---

## Summary

Four themes dominate this beta.

Container engines stopped being built in. Docker and Podman are now plugins on a proper
contribution point, core ships with no engine of its own, and the engine socket is discovered
rather than assumed — so Studio works with whatever is actually installed, says so when nothing
is, and stops silently launching Docker Desktop.

The decoder plugin system landed, giving the binary editor and generated-code panel .NET IL,
native, JVM and WebAssembly listings, all delivered as installable plugins rather than baked in.

Graphics settings collapsed from three switches into one Graphics Acceleration level, and a
broad performance pass cut work out of the hot paths — IPC, dock dragging, logging, background
workspaces and the agent transcript.

The agent panel gained per-conversation task controls and a Stop button that always lands.

## Known issue — the `decoders-v1.0.0` tag is orphaned

Recorded here so it is not rediscovered later. **It does not block this release.**

The `decoders-v1.0.0` tag points at `89334cf2`, which is reachable from no branch. The sequence:

1. `89334cf2` was the tip of `feature/decoder-contribution-point`.
2. The tag was cut and the release published at **2026-09-03T21:10:27Z**.
3. PR [#585](https://github.com/onix-labs/onixlabs-studio/pull/585) was **squash-merged** at
   **2026-09-03T21:24:06Z**, 14 minutes later, producing the new commit `a13ff73f`.
4. The squash orphaned the original branch commits, and the branch was deleted.

The tag is now the only ref keeping `89334cf2` alive. Git will not garbage-collect a tagged
object, so the commit is safe, but it is not part of main's history.

**The published assets are reproducible.** Diffing the tag against main across `plugins/` and
excluding `plugin.json` yields an empty diff — the decoder source is byte-identical. The
`plugins/protocol` tree hash (`86ba0904`) is the same at both revisions. The only difference is
that `89334cf2` still carries placeholder `sha256` values (all zeros); the real checksums landed
on main via the squash commit `a13ff73f`.

**Recommended fix at decoders v1.0.1:** tag the merged commit on `main`, not a feature-branch
tip, and only after the checksums are filled in.
