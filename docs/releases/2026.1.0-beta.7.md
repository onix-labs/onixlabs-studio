## Summary

Three themes make up this beta.

The code editor is Studio's own throughout. Every pop-up Monaco used to draw is now drawn by Studio
and wired to Studio's features (epic [#946](https://github.com/onix-labs/onixlabs-studio/issues/946)):

- **Find and Replace** open Studio's Search panel, which can be scoped to the workspace, the
  project, open files, the current file or the selection.
- **Go to Symbol and Go to Line** use a quick-open box or dialogs, whichever you choose.
- **Right-click** opens Studio's menu.
- **Find All References** fills a References panel, and Go to Definition never peeks.
- **Rename** asks in Studio's own prompt and applies across files.
- **Quick fixes** come from a Studio-drawn bulb in the gutter.
- **Hover cards, autocomplete, parameter hints** and a **colour picker** are Studio's.

A guard test keeps any Monaco widget from coming back.

The security and audit follow-ups deferred from beta.6 land:

- "Always allow" on a shell command now covers that exact command, not every command.
- Agents can no longer write Studio's own data folder.
- Sideloaded plugins are opt-in in packaged builds.
- The log table, scroll bars and streaming replies are lighter.

Prompt profile and skill changes reach an open Claude or Codex conversation on its next message.

Fixes that came out of this work:

- **Every request about a cursor position** (completion, hover, definition, references, rename,
  fixes) now brings the language server up to date first. A completion on `.` could overtake the
  change that typed it and list the wrong names.
- **Clicking a search result, a reference, or Go to Definition into another file** opens the file
  in the workspace and selects the match, centred.

**Upgrade note:** the editor's pop-ups, menus and shortcuts behave like Studio's rather than VS
Code's:

- **⌘F** opens the Search panel.
- **F3 / ⌘G** no longer step through matches.
- **F7 / ⇧F7** (the accessible diff viewer) do nothing until a Studio version lands
  ([#1026](https://github.com/onix-labs/onixlabs-studio/issues/1026)).
- **Monaco's command palette (F1)** is gone.
- The new editor shortcuts can't be rebound yet. Keybinding profiles are planned in
  [#1036](https://github.com/onix-labs/onixlabs-studio/issues/1036).
