## Summary

This beta's headline is that the macOS builds are signed.

Until now Studio's macOS builds were unsigned, so macOS refused to open them because "the developer
cannot be verified", and you had to right-click and choose Open, or clear the quarantine flag with
`xattr`, before Studio would start. Beta.12 is the first release whose macOS builds are signed by
ONIXLABS LIMITED with its Apple Developer ID and notarised by Apple, so macOS opens them like any
other downloaded app. Every disk image and zip is checked before it is published: signed by the
ONIXLabs team, intact, its notarisation ticket stapled, and accepted by Gatekeeper. The Windows
installer is still unsigned, so Windows still warns before it runs.

Every tab and tool now runs on one dock, the one the workspace already used. The code, Markdown,
binary, agent and terminal tabs, the System Monitor, Mission Control, the AI and Plugin Managers and
Containers each keep their main content in the middle, with panels around it, such as the Agent,
Find, Outline or the run terminal, that you can drag, dock, tab together, collapse and close. A closed
panel comes back where it was, and a new tab opens with the arrangement you last made. The fixed
splits elsewhere, such as query results and API responses, share one split panel that remembers
their sizes.

Nothing runs from a folder until you trust it. Language servers, project tools, formatters,
terminals, debuggers and agents all wait for your answer, a clone asks before it downloads anything,
and Scan with AI lets an agent read an untrusted folder, and do nothing else, before you decide.

Each kind of notification can be switched on or off, and far more things say when they finish while
you are elsewhere: test runs, debug sessions, terminals, clones, package changes, model downloads,
background fetches and CI. Agents learn a persona from your conversations, which replaces prompt
profiles. Conflicted files open in a merge tool, and merged branches can be deleted in one go. Go
reaches parity with gopls, TOML gets a language server, and the System Monitor is a tabbed dashboard.

## Plugins

These releases come in with this beta. Install or update them from the Plugin Manager.

- **claude-harness 0.22.0** can be kept from an untrusted folder's own settings, hooks and tool
  servers ([#1520](https://github.com/onix-labs/onixlabs-studio/pull/1520),
  [#1547](https://github.com/onix-labs/onixlabs-studio/pull/1547)).
- **git 0.10.0** (Delete Merged Branches,
  [#1541](https://github.com/onix-labs/onixlabs-studio/pull/1541),
  [#1549](https://github.com/onix-labs/onixlabs-studio/pull/1549)) and **git 0.11.0** (locked SSH
  keys and unknown SSH hosts, [#1545](https://github.com/onix-labs/onixlabs-studio/pull/1545)).
- **docker-engine 30.4.0** and **podman-engine 7.4.0** report the container events behind the
  exited, out-of-memory, unhealthy and restarting notifications
  ([#1512](https://github.com/onix-labs/onixlabs-studio/pull/1512),
  [#1579](https://github.com/onix-labs/onixlabs-studio/pull/1579)).
- **go-tests 0.2.0** debugs a Go test from the Tests panel
  ([#1529](https://github.com/onix-labs/onixlabs-studio/pull/1529),
  [#1579](https://github.com/onix-labs/onixlabs-studio/pull/1579)). It needs plugin API 1.30, so
  beta.10 and older keep installing go-tests 0.1.0.
- **Live Server 0.1.0**, its first release: Open with Live Server
  ([#1526](https://github.com/onix-labs/onixlabs-studio/pull/1526),
  [#1579](https://github.com/onix-labs/onixlabs-studio/pull/1579)).

**Upgrade note:** Studio does not run an older Claude plugin in a folder you have not trusted; update
Claude in the Plugin Manager to use agents and Scan with AI there.
