## Summary

Four themes make up this beta.

Agents are plugins all the way down. Signing in to Claude now happens in the Claude plugin, using the
Claude CLI you chose in Settings, and the app ships no agent SDKs at all, which takes about 270 MB of
native binaries out of every download. Claude's replies stream in as they are written, and a turn
Claude starts to report a finished background task shows "Working" straight away. Codex can now run
its bundled copy, the `codex` on your PATH, or a custom path, as Claude already could.

Agents stay out of your way. An agent working in one tab no longer switches you to it when it opens
a file: what it opens is added behind what you are reading, a new tab it opens is not switched to,
and a terminal it opens never takes the keyboard. Agent conversations gain a text-size setting and
draw markdown the way the Markdown editor does.

Unsaved work is never lost. Switching layouts, undo, redo and Reset all used to be able to drop a
document with unsaved changes without asking. Now nothing can.

The terminal links what it prints. Web addresses and workspace file paths are coloured as links, and
⌘-click (Ctrl-click elsewhere) opens them: an address in the browser, a file in the well at the
printed line and column.

## Plugins

These releases come in with this beta:

- **claude-harness 0.16.0** signs in through the plugin, streams replies and reports when it starts a
  turn. It works with beta.8 too, which simply doesn't use the new sign-in or turn reporting.
- **codex-harness 0.9.0** runs Codex from its bundled copy, your PATH or a custom path. An older
  Studio ignores the new setting and keeps using the bundled copy.

**Upgrade note:** update the Claude plugin to 0.16.0 in the Plugin Manager. Studio offers the update
when it starts.
