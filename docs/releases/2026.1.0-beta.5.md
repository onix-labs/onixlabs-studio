# ONIXLabs Studio 2026.1.0-beta.5 — what changed

**Range:** `v2026.1.0-beta.4..main` (`c9914a25`)
**Span:** 2026-09-07 → 2026-09-14
**Commits:** 113 total, 108 excluding merges

---

## Summary

Five themes dominate this beta.

Every AI provider is a plugin. Claude, Codex and the Vercel AI SDK each run out of process behind
one agent protocol, installed from the Plugin Manager; core ships with no provider at all, and a
configuration names the plugin that runs it. The protocol carries the whole turn — tools, prompts,
credentials asked for rather than handed over, sessions held open across turns, Remote Control —
so a harness reaches parity with what used to be built in.

A setup wizard runs on first launch and after an upgrade. It walks a tree of what is installed —
a step per plugin category, a leaf per language or provider — and shows what changed since the
version last run.

The agent docked in a workspace runs on a surface of its own and can act as the Explorer does:
see the well, open diffs, read source control, drive the workspace's terminal panel, and create,
rename or delete entries in the tree. Standing prompt profiles and a skill library scope
instructions by surface and language.

Background tasks report back. A task that finishes while the conversation is idle is now reported
with the agent's own follow-up; Stop settles a task within a second; a task Studio can no longer
reach is untracked with a note rather than listed forever. The agent controls follow one table per
phase, and previous messages recall on Alt+Up/Down, giving Shift+Up/Down back to selection.

Markdown editing in the document well grew a formatting toolstrip, open-in-tab, selectable
dividers, and fixes for GitHub alerts, sub/superscript and false dirtying; mermaid moved to 12.

process speaking the agent protocol.
